# `@deviation`

Para fugir de um padrão de propósito, escreva `@deviation <regra>: <por quê>`: na função, para regra de tela; antes do elemento, para regra de nó. Só padrão se declara; lei não.

Dados e arquivos próprios: importe só de dentro da sua pasta (`./dados`, `./components/Etapa`). Arquivo sem JSX (dados) não passa pelo filtro de valores brutos. O que o checador não lê aparece como "não lido" e é contado; a medição da tela renderizada continua valendo.
