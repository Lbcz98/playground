# source-command-explore

Use this skill when the user asks to run `/explore`.

Follow `.claude/commands/explore.md` from start to finish.

- Every explorer pack includes the topics that option needs and 2 or 3 gold cards from `design-brain/toolbox/references/`. The explorer studies the sheet and the notes and does not copy them. It does not read `DESIGN.md`, `playbook.md` or `judge.md` in full.
- After the layout check is `ok`, the art director picks the best 1 or 2 options. The playbook judge reads only `pack/judge.md`. One adjustment is applied once, to those options. `none: ready` still requires a Direção visual block and no Critical or Warning from the judge.
- Tune controls are built when the designer asks, not while the options are written.

`/explore-playbook` is the same command.

Talk about options and screens, never about Git.
