# Direction: the block

Applies when: the art director writes the Direção visual after the answers. This is DIRECAO §6. The block replaces the brief's Referências and Fio condutor fields.

```
**Direção visual**
- Tom: <3 words> · temperatura: <cold/neutral/warm and why, one phrase>
- Fio condutor: <one sentence; the thing all options share>
- Referência principal: <name or "repertório: <entry>"> · teoria confirmada: <the mechanisms the designer confirmed, each with its measure>
- Levar: <mechanism: how it shows up in a card with the kit> (one line each, 2 to 4)
- Evitar: <mechanism: what it would look like if it crept in> (one line each, 1 to 3)
- Palavras do designer: "<quote>", "<quote>"
- Inegociável: <the dealbreaker>
- Teste de fidelidade: <one yes/no question a judge asks of a PNG>
- Distância por opção: 1 fiel · 2 reinterpretada · 3 reinterpretada · 4 contraponto
```

The "Levar" and "Evitar" lines are the contract: a writer reads them like a rule, a critic checks them like a rule. Quote the designer's words in `Palavras do designer`. Every `Levar` and `Evitar` line names a mechanism and how it shows up with the kit. Token names only if read from a tool result. Set `Distância por opção` for the number of options (at least one faithful, at most one counterpoint). The Foco's group sits inside the thread: the direction serves the focal group, never competes with it.
