# Arrangement

Applies when: the option is interactive, or it lays items out in a row the keys would move through.

Items that ←/→ move between sit side by side, never stacked in a vertical list. A vertical list in a card whose keys are ←/→ is a broken control, not a style. If the data is naturally a list, change the data (a rail of 3 to 4 steps) or the key model, not the pairing.

The layout check prints the mismatch as `eixo`. Report it on its own, apart from any "looks like an accordion" remark.

This is `DESIGN §7.6`.
