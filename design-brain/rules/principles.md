# Principles

Applies when: every card. Judge with these. The measurable rule each one points at lives in that topic, not here.

- **Contrast:** softer colour for description against title, size differences.
- **Proximity:** groups of one kind, actions next to actions, label next to its title. Gap recipe: `surfaces.md`.
- **Hierarchy:** size, colour, type. The focal group: `focal-point.md`.
- **Progressive disclosure:** segment. Use paging or a rail of cards instead of one overloaded component.
- **Respiro:** the criterion that most separates good from bad. "Claustrofóbico" is a rejection.
- **Tone before polish:** does the design match the product's tone and narrative? (A cold data map did not fit a light show.)
- Dieter Rams, in the designer's order: useful, aesthetic, unobtrusive. Honest weighs least.
- Judge intent, not personal taste: the brief, the place it lives, something new to the system.
- An invented function is allowed when the rationale justifies it and it fits the interaction. Judge it on that.
- The agent decides alone what has a well-defined rule. The agent asks when the request goes against a fundamental of the system, when a sharp change to behaviour seems needed, or when a rule is missing. Deviating from the kit is the designer's decision.

Don't: changing what was not asked. The fix changes only the aspect pointed at.
