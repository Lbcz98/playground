# Check: remote keys

Applies when: the option is interactive. Norma: `remote-keys.md`.

Name the one catalog pattern (`node scripts/explore-ref.mjs --padroes` and `--teclas`). More than one pattern, or a behaviour in no catalog row, is Critical.

Anything the remote cannot do is a finding: hover, mouse click, drag, swipe, scroll, tooltip, dropdown, text field. ↑/↓ with `preventDefault` is Critical.

For a grid card, name its type (1 to 4) and check the focus target, that Enter fires only the focused node, that directions leave a type 1, 2 or 3 card, and that type 4 follows the vertical order. No long press. No row of chips inside the card. A break is Critical. A Content Card of a contextual interactivity is not judged by that table.

Disclosure look (a chevron that opens a row) is Critical. False affordance (looks interactive, no key reaches it) is a Warning.
