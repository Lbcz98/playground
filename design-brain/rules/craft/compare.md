# Compare

Applies when: every playbook judgment.

Compare in words with the gold set (`design-brain/toolbox/references/`, the poster card and the selector card). The good card: one interaction, one image as the lure, info on top and actions below, generous respiro. The bad set: 2 or 3 interaction types, several accent colours, no strongest element, crowded. Say which set each option is closer to and why.

Do not invent numbers beyond the laws that already have one. Do not call a card crowded only because its information sits together at one edge of a full-bleed photo: the designer rated that layout among the best.

When an option replaces an older one, compare them. If it is poorer (less composition, a smaller graphic, a plainer chart) while obeying the item rules, say so as "Reduce items, not richness".
