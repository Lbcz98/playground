# Visual direction

Vocabulary (visual direction, thread, mechanism, distance, critique round, interview round): `CONTEXT.md`.

This file is the index. The handbook is split so each mode reads only its topics. `DESIGN.md` wins on what may be drawn; these files decide what is worth drawing.

| File | Who reads it |
|---|---|
| [`rules/direction-stance.md`](rules/direction-stance.md) | art director, every mode |
| [`rules/direction-lenses.md`](rules/direction-lenses.md) | interview, when a reference is read |
| [`rules/direction-vocabulary.md`](rules/direction-vocabulary.md) | interview, direction, critique, and every explorer pack |
| [`rules/direction-repertoire.md`](rules/direction-repertoire.md) | interview, when there is no reference |
| [`rules/direction-boldness.md`](rules/direction-boldness.md) | direction, critique, and every explorer pack |
| [`rules/direction-interview.md`](rules/direction-interview.md) | interview |
| [`rules/direction-block.md`](rules/direction-block.md) | writing the Direção visual |
| [`rules/direction-critique.md`](rules/direction-critique.md) | critique, and every explorer pack |
| [`aprendizados-continuos.md`](aprendizados-continuos.md) | the top table, then only the section the mode names |

An explorer pack pastes vocabulary, boldness and critique. It does not paste the lenses, the repertoire or the interview. The art director does not read this index in place of the mode's files, and does not read `DESIGN.md` in full: the drawing limits it needs are the topic files the critique names.
