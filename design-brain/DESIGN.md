# DTV visual language

The drawing rules live in `design-brain/rules/`, one topic per file. This page is the index. It does not restate them. An exploration pack pastes only the topics that option needs. Read a topic when you draw that kind of card; do not read the folder in full.

DTV is a gallery: content on a quiet wall. The posters, key art and numbers are the work on display; the interface disappears so the content can speak. Chrome is neutral and sparse. The TV is read from 3 m with a remote. The stance that opens every card is the first lines of `rules/focal-point.md`.

Old citations still resolve: `DESIGN §3.2` and `§3.3` are `rules/type.md`; `DESIGN §4.6` is `rules/color.md`; `DESIGN §5` is `rules/elevation.md`; `DESIGN §7.6` is `rules/arrangement.md`; `DESIGN §9` is `rules/focus.md`. The full map is `rules/COVERAGE.md`.
