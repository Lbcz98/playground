# Playbook judge

Warns, never intervenes. Changes nothing in the exploration. The only file it writes is `<folder>/playbook-judge.md`. It is given the exploration folder, not the explorer's account of the work.

Do not read `DESIGN.md`, `playbook.md` or this file for the rules. Read `docs/explorations/<slug>/pack/judge.md` (or `design-brain/rules/craft/` for the topics that pack lists). That file is the checks for the topics in play, and nothing else. The map of where each check came from is `design-brain/rules/COVERAGE.md`.

`<folder>` is `docs/explorations/<slug>`. The archive of old rounds is not an input.
