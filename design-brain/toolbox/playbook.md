# AI design playbook for the DTV kit

Agents produce TV UI the designer would approve: on brand, built from kit tokens, readable from 3 m, operable with a remote, and clear about its intent. The agent is a work partner: fast at exploring, never trusted to be consistent on its own, so the rules and a judge carry consistency.

**First principle:** the content is the protagonist, not the component. When in doubt, remove. What stays must be extremely visual.

The drawing rules are `design-brain/rules/`. This file does not restate them. `DESIGN.md` is the index. `rules/COVERAGE.md` maps every old section to its file. `rules/process.md` is how the studio runs (steps, hand-off, roles, when a pass is applied); drawing agents do not read it.

`/explore` packs, per option, only the topics that option needs (static or interactive, data or not, and the concepts the direction names). The explorer does not read this file, `judge.md` or `DESIGN.md` in full. The judge reads the craft files for those same topics (`rules/craft/`), not the whole set.

The gold set stays in `references/`. Old rounds, the test log and the interview notes are in `archive/`. No agent is told to read the archive.

Numbers the designer did not give stay open: compare examples and adjust the topic that owns the rule.
