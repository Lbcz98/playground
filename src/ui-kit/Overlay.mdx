# Camadas — the overlay of a screen

{DTV_SCREEN_LAYERS.rule}

An overlay is never chosen shade by shade. Each screen type has one fixed combination,
set by where its components occupy the screen: a row of buttons along the bottom edge
darkens the bottom, a column of cards on the right darkens the right, a notification in
the top-right corner darkens that corner alone. Every piece is pure black, so the pieces
compose in any order — the result only depends on which ones are on.

## The pieces

`base` is the scrim (10% black over the whole frame) and says "UI is on screen". The six
shades name the edge or corner the content sits on. The two transient overlays — an alert
bug and a notification over the clean broadcast — carry no scrim, so the picture behind
them stays untouched.

## Using it

A screen names its model; the engine paints the shades under the content. A blueprint is
the content only.

```tsx
<div style={{ position: 'relative' }}>
  <video … />
  <ScreenOverlay model="home" />
  <MainMenu … />
</div>
```

`Overlay` is the single-direction version of the same tokens, for a component that brings
its own shade rather than a whole screen:

```tsx
<Overlay direction="bottom-left" />
```
